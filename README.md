# Calculadora Básica em Java

Este é um projeto simples desenvolvido em **Java** para consolidar os fundamentos da **Programação Orientada a Objetos (POO)**. O foco deste exercício foi a criação de métodos com parâmetros e a manipulação de retornos.

## 🚀 Funcionalidades

- **Cálculo de Dobro:** Recebe um valor inteiro e retorna o resultado multiplicado por dois.
- **Estrutura Limpa:** Código organizado seguindo as convenções da linguagem Java.

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** Java 17+
- **Paradigma:** Orientada a Objetos

## 📚 Aprendizados

Durante o desenvolvimento deste projeto, pratiquei:
1. Criação de classes e instanciamento de objetos.
2. Definição de métodos com tipos de retorno específicos.
3. Passagem de argumentos para métodos.
4. Diferenciação entre atributos de classe e variáveis locais/parâmetros.
